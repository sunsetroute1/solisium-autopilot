About the Gate of Memory

Gate of Memory is a recurring world event in Throne and Liberty that opens on a fixed interval. The event itself lasts roughly three minutes, after which there is a set gap before the next one opens. This timer counts down to the next opening and lists every upcoming occurrence for the next 24 hours, converted to your local timezone.

All times are converted to your local timezone automatically — there's nothing to set up. Toggle the bell on any occurrence to get a browser reminder shortly before it starts; keep this tab open for reminders to fire.
